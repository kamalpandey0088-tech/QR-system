# Lumina POS & QR System
**Version 1.0.0 - Final Production Release**

This repository contains the complete, production-ready QR Ordering System.

## Features Included in V1:
- Zero-Lag Optimistic UI Cart
- Accurate 5% GST Calculation synchronized with the backend database
- UPI QR Code integration on the checkout invoice
- Kitchen Display System (KDS) with Cash/UPI badges
- Admin Dashboard with QR Code Generator
- Mobile-friendly Login with invisible space protections
